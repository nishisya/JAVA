# Pokémon Ga-Ole console game
The program consists of the basic features of ‘Battle and Catch’ mode including :

1. Start "Battle and Catch" mode

2. Catch time!

3. Depart for battle

4. Let's Go! Battle!

5. Catch Pokemon!

6. Check your results!

+ An add-on feature a.k.a the "Ga-Ole Disk" system has also been added to the simple Pokémon Ga-Ole game. Every Pokémon that is captured can be recorded and displayed as a Ga-Ole Disk.
